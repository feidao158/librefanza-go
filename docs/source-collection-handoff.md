本文保留当时的验证记录。项目现已停止支持 MySQL，文中的 MySQL 验证步骤仅作历史参考，不适用于当前版本。

更新时间：2026-11-07

## 本次继续处理

- 根据用户要求，JavBus 已停止新增检索、自动探测、定时和手动采集、历史补采及封面补采；保留已有来源记录和本地解析能力。旧任务不会继续访问该来源。现有运行实例尚未更新，因此上述行为仅适用于本工作区构建的版本。
- 手动列表采集在有效详情成功保存后标记来源已验证，保存或标记失败仍向任务返回错误；番号搜索不触发该标记。
- 当前代码已分别通过隔离 MySQL、PostgreSQL 全量后端测试，前端 22 项单元测试、19 项 PC 浏览器测试、生产构建及 Go vet。浏览器测试的接口使用模拟数据，不代表真实上游验收。
- 根据用户要求不再进行长期压力测试。其他来源的外部访问限制、历史数据升级前备份及真实生产环境验收仍适用下文说明；延期与数据库错误分类仍需继续复核。

以下为此前交接记录，涉及 JavBus、已完成验证和手动采集验证状态的描述以本节为准。

## 当前状态

- 本次工作停在未提交的工作区，尚未部署到现有运行实例。原有实例仍使用此前的镜像和数据库结构，不包含本次改造。
- 工作区中存在本次开始前已有的前端修改，未回退；后续继续时应先检查 `git status` 和各文件差异，不要直接覆盖这些修改。
- 本次启动的临时应用、浏览器测试容器及两种测试数据库已停止。此前运行的项目容器和数据未删除。
- 本次构建的 `librefanza-chromium-verify:local` 只是临时验证镜像，早于最后的高清封面保护迁移，不能当作最终交付镜像。

## 已实现

- AVMOO、JavLibrary 已从新检索、定时采集和手动采集入口移除；旧来源的历史记录与本地原始数据解析能力保留。旧采集任务执行时以来源已停用结束，不再自动重试。
- 接入 JavDB、JavBus、JavBooks、JavQuery 的检索、详情解析和分页采集；未识别的页面和站点验证页不会当作正常空结果。
- 来源健康状态、限速与冷却保存在 SQL 中，支持失败分类、延期及恢复；管理页面显示来源状态。新来源自动探测成功且详情入库后，默认按 30 分钟周期启用，管理员手动操作开关后不再自动覆盖。
- 影片卡片优先使用手动封面、来源大图，再回退缩略图。历史小图补采按像素比较更新；已确认改善的来源封面增加数据库标记，防止后续来源数据将其覆盖回小图。管理员手动封面不被补采覆盖。
- 新来源历史补全及疑似小图修复使用分批任务和持久化进度；旧来源无效详情支持跳过计数。FC2 当前页面的发行日期解析已修正。
- 动态页面使用 Chromium；Compose 配置了非 root 运行、浏览器沙箱、限制命名空间的 seccomp 配置和 init 进程。浏览器请求限制单并发，并对目标地址执行公网校验。
- 系统 DNS 仅返回 Fake-IP 时，浏览器和图片尺寸检查会使用 Cloudflare 加密 DNS 取得并校验公网地址；该回退需要外网访问，并会向该服务发送查询域名。

## 未完成与待处理

1. **最终整体验证尚未重跑。** 在最后一次完整双数据库回归之后，又修改了来源冷却、旧来源分页、退役任务提示、高清封面保护和 Compose init 配置。最后的封面保护回归仅单独在 PostgreSQL、MySQL 上通过；应基于当前全部文件重新运行完整后端、前端和 PC 浏览器测试。
2. **最终镜像尚未重新构建和验收。** 应重新构建包含 `00020_repaired_cover.sql` 的镜像，在隔离数据库中验证安装、升级、自动探测、历史补采、Chromium、关闭与重启恢复。不要直接使用上述临时镜像发布。
3. **手动启用新来源后的验证状态仍需完善。** 后台自动探测仅处理 `auto=true` 的来源；管理员手动启用会设置 `auto=false`。目前手动采集即使成功，也不会在保存后标记来源已验证，因而可能不会启动该来源的历史影片补全。需要在成功保存有效列表详情后更新验证状态，并增加测试。
4. **延期与任务结果还需复核。** 单个来源发生实际请求错误时，补全任务仍可能返回错误并触发原任务重试；长期不可用来源对应的手动分页任务也可能耗尽重试次数而需要人工重试。应验证大批量故障时的日志量、延迟、恢复及任务状态，确保数据库写入错误不会被当作普通来源延期。
5. **浏览器进程回收需长时间验证。** 临时应用曾在未启用 init 时产生已退出但未回收的 Chromium 子进程；已在 Compose 启用 init。一次真实 Chromium 请求结束后检查仅剩 init 与等待进程，但尚未做长时间、多任务及异常退出压力测试。
6. **JavBus 尚未真实采集成功。** 当前环境返回年龄验证页面；需由管理员依法完成站点要求并配置允许使用的有效会话后，再验证列表、番号检索、详情和图片。不要绕过验证，也不要把验证页视为成功。
7. **其他来源的外部条件仍有限制。** 当前环境 Fanza 未配置 API 凭据，SOD 出现网络或 DNS 错误，MGStage 和 Jable 返回 HTTP 403；需要在实际部署网络及合法配置下复测。站点可用性和页面结构可能变化。
8. **采集能力与性能需继续核验。** 四个新来源的各分页、日期范围和长历史采集尚未逐一做完整真实站点验收；Chromium 当前每次动态页面请求启动浏览器且限制单并发，大量历史影片补采的耗时和资源占用仍需实测。
9. **历史图片效果尚未在现有数据库验收。** 本次未修改现有运行实例的影片、封面或任务数据；升级后应先备份，再观察低优先级补采进度，抽查大图尺寸、手动封面和来源版本是否保持正确。

## 后续验证命令

使用专用测试数据库，不要指向现有业务库：

```bash
cd backend
GOMAXPROCS=2 LIBREFANZA_TEST_DB_DRIVER=postgres LIBREFANZA_TEST_DB_PORT=<测试端口> go test -p 1 ./... -count=1
GOMAXPROCS=2 LIBREFANZA_TEST_DB_DRIVER=mysql LIBREFANZA_TEST_DB_PORT=<测试端口> go test -p 1 ./... -count=1
GOMAXPROCS=2 go vet -p 1 ./...
cd ../frontend
npm test
npm run build
```

PC Playwright、最终 Docker 镜像与真实来源检查应在隔离环境单独执行；所有临时服务在验证后停止。部署及浏览器沙箱要求见项目根目录 `README.md`。
